Transcript

How it works. The first run downloads the chosen model into your browser cache (one-time per model), then transcribes on your device. A modern GPU (WebGPU) is dramatically faster; without one it falls back to CPU and long files can take a while. Long audiobooks are memory-heavy to decode in a browser — if a multi-hour file stalls, try a shorter clip or split it first.
