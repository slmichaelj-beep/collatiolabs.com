In production · Procurement pipeline01

The Machine

The procurement pipeline Collatio runs on its own SAM.gov bids. Solicitations arrive from the SAM.gov API and 1,200+ public procurement sources; the pipeline classifies product versus service bids, drafts responses against an explicit quality gate, verifies SAM registration status (UEI/CAGE match), and applies pricing from a founder-approved rate card. A human approves every submission — nothing leaves the system without that click.

VerifiedIn daily use · 140,000+ records under management.

In production · Host and network observer02

Argus

Runs in production as a read-only host and network observer: it records process and network forensics and assembles incident timelines with supporting evidence. Enforcement mode — stopping a host’s outbound AI and web traffic on a high-severity finding — is built and working; it is not switched on in daily use.

VerifiedIn daily use; its published API contract is consumed in production by The Machine.

Demo on request · Decommission archives03

Custodia

Archives for systems you are retiring. Each archive ships with a portable database, an Ed25519-signed completeness certificate, and a single-file verifier — standard library only — that the customer keeps. The archive opens and proves its own integrity with no one from Collatio in the room. Download the verification bundle — a sample archive, its signed certificate, and the verifier. Verify it yourself without contacting us.

Notis

Seal a file so any later change is evident. Anyone holding a sealed file can check its integrity — without calling Collatio.

Demo on request · Verifiable data reduction05

Comprimo

Reduce a dataset and prove the reduction faithful. Merkle commitments establish the integrity of every reduced set; exactness is a hash comparison of the reconstructed output against the original. Recovery is bit-for-bit, and an audit certificate accompanies every run.

VerifiedRound-trip reconstruction matched the original bit for bit. Re-runnable live.

An agent runtime that keeps sensitive prompts on local models. Agent state survives process failure, and three model backends sit behind one interface — the model can change without the workflow changing.

How we work

Start with one critical workflow.

One front door: the Executive Systems Review.

Fixed price, scoped at intake. You bring the workflow your organization cannot afford to leave manual; you leave with a scoped build path — source material, handoffs, risks, decision gates, technical approach — and a first milestone you can hold us to. Acceptance criteria agreed in writing before work begins. Payment on accepted milestones only. Pricing from a standard rate card. You work directly with the principal.

Capture — records that agree with their source

Extract, validate, and package data from PDFs, spreadsheets, forms, and portals — every value checked against the record it came from. Normalize and reconcile conflicting records, with outputs your reviewers can accept or reject.

Automate — status that survives the handoff

Internal platforms — dashboards, review queues, status ledgers — that make ownership, evidence, and next actions visible. Integrations that connect forms, files, email, databases, and APIs so work stops disappearing between systems.

Govern — AI drafts, a person approves

AI-assisted extraction, classification, drafting, search, and routing — with human approval on every consequential output, and every output checked against its source record.

Good first engagements

An accountable owner, a recurring high-value workflow, usable source material, and a clear definition of done.

Security & data handling

Sensitive data stays in your environment.

For sensitive workloads, the default is deployment in your environment, on local models. Vera keeps sensitive prompts on local models, and Argus is built to stop a host’s outbound AI and web traffic on a high-severity finding.

No client data is used to train models. Deliverables encrypt data in transit and at rest.

Continuity

Key-person continuity.

The model, plainly: principal-led, with engaged senior specialists brought in under the same acceptance gates. Continuity is engineered into every deliverable — each milestone ships a documented, tested, handoff-ready repository. No deliverable depends on any single individual. Including the principal.
