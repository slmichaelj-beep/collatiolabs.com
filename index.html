Evidence

Credibility comes from systems that can be inspected, tested, and handed off.

Running · revenue system01

The Machine

A government-contracting revenue engine: discovers solicitations across 1,200+ sources and the SAM.gov API, classifies product-versus-service, drafts against a quality gate, verifies SAM/CAGE/UEI, prices from a founder-approved rate card, and stops at the submit button — a human always clicks. Verified: running on one PostgreSQL database with 140,000+ proof-disciplined records; 3,589 tests collected, 625 test files passed in the full run of 15 Aug 2026.

Records · verifiable archives02

Custodia

Decommission a legacy system into an archive that proves itself: an RFC 6962 Merkle-committed store, an Ed25519-signed certificate, and a dependency-free verifier shipped inside every archive. Verified: 183 tests passing; an end-to-end run built an archive, verified it, altered one record, and re-verification correctly failed. Internal demonstration.

Documents · sealing03

Notis

Document sealing and multi-party signing with tamper detection across SHA-512, SHA3, and BLAKE3. Verified: 489 tests passing; a sealed file verified, then failed verification the moment its content changed. Not yet deployed as a service.

Storage · verifiable04

Comprimo

Deterministic data reduction with Merkle proofs and audit certificates: reduce storage and prove exact, bit-perfect reconstruction. Verified: exact round trip reproduced directly under chaos and load tests. Internal demonstration.

Security · host observer05

Argus

Local-first host and network observer with a published API contract: process and network forensics, incident timeline, evidence, and a software breaker that stops a system's outside AI and web calls on a high-severity finding. Verified: API contract published and consumed by The Machine's egress guard; tests pass; running as a read-only host observer.

AI · agent runtime06

Vera / Anima

A local-model AI agent runtime whose state survives process death, whose learning is verified numerically, with three interchangeable model backends and a privacy guard that keeps sensitive prompts on local models. Verified: continuity, learning, model swap, and privacy routing each demonstrated. Internal demonstration.

Running · web application07

itsme

A live web application with consent, age verification, geo/IP policy, presence and push, block enforcement, and a self-indexing knowledge database of its own code, routes, and migrations. Verified: live (HTTP 200); knowledge database counts reproduced.

Documents · PDF08

Folia

Native macOS PDF workspace built with SwiftUI and PDFKit: forms, signatures, markup, page tools, local OCR, packaged distribution.

Marketplace09

Praeco

Trust-based introduction marketplace with Flask APIs, Stripe Connect architecture, security modules, migrations, documentation, and 24 test files; a Next.js rewrite in progress.
